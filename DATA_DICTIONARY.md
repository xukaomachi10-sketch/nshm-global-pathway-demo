# Internal Operations MVP - Data Dictionary

## Conventions

- Primary keys are UUIDs generated by `gen_random_uuid()`.
- Times use `timestamptz` in UTC; dates without time use `date`.
- Mutable business tables include `created_at`, `updated_at`, and `deleted_at`.
- `deleted_at is null` means active; deletion is soft unless a reviewed retention process states otherwise.
- `activity_logs` is append-only and has no soft-delete field.
- `jsonb` fields hold extensible attributes, not core relational keys or statuses.
- Seed data is fake. Codes begin with `FAKE-`, emails use `example.invalid`, and profiles contain `is_fake=true`.

| Column | Type | Null | Key/default | Description |
| --- | --- | --- | --- | --- |
| `id` | uuid | No | PK, generated | Log ID |

| `action` | text | No |  | Stable action code, e.g. `case.created` |
| `confidentiality_level` | `confidentiality_level` | No | `restricted` | Log handling level |
| `previous_data` | jsonb | Yes |  | Approved before-state subset |
| `new_data` | jsonb | Yes |  | Approved after-state subset |
| `metadata` | jsonb | No | `{}` | Request ID, source, reason; no secrets |

Do not store passwords, tokens, service keys, raw documents, or unnecessary sensitive payloads in audit JSON.
